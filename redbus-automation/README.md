# RedBus Selenium Automation Project

## Project Overview

This project automates the RedBus bus booking workflow using Selenium WebDriver with Java.

The project follows the Page Object Model (POM) design pattern to improve code reusability, maintainability, and readability.

## Technologies Used

Java

Selenium WebDriver

Maven

TestNG

Page Object Model (POM)

Eclipse IDE

Git and GitHub

## Test Scenarios

Homepage title verification

Source and destination city selection

Journey date selection

Bus search

Bus search results verification

Seat selection

Boarding and dropping point selection

Passenger details entry

## Project Structure

src/main/java – Page classes

src/test/java – Test classes

pom.xml – Maven dependencies

testng.xml – TestNG configuration

## How to Run

Import the project into Eclipse as a Maven project.

Update Maven dependencies.

Run testng.xml using TestNG.
